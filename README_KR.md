# 산스 AI루틴클럽 - 텔레그램 봇

> 루틴 즉시 인증, 출석률 정산, 주간 리포트 및 AI 코칭을 운영하는 텔레그램 커뮤니티 봇입니다.

[View English README](./README.md)

산스 AI루틴클럽 봇은 멤버가 봇과의 1:1 대화에서 사진+캡션 또는 `/reg [인증 내용]` 텍스트 명령으로 별도 루틴 등록 없이 즉시 인증하고, 인증 시 신규 멤버를 자동으로 `Users` 시트에 등록하며, 그룹방에 인증 소식을 공유하도록 설계되어 있습니다. Google Sheets를 데이터베이스로 사용하고, Ollama 로컬 모델로 AI 이미지 코칭과 주간 브리핑/카드뉴스를 생성합니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 즉시 루틴 인증 | 1:1 대화방에서 사진+캡션을 보내거나 `/reg [인증 내용]`을 입력하면 `Routines` 시트 의존 없이 즉시 인증됩니다. |
| 신규 멤버 자동 등록 | 새로운 멤버가 들어와서 첫 인증(사진+캡션 또는 `/reg`)을 하면 `Users` 시트에 자동으로 멤버를 추가하고 바로 인증 처리합니다. |
| 내 현황 모니터링 (`/status`) | `Logs` 및 출석률 계산을 기반으로 오늘/이번 주/누적 인증 건수, 이번 주 출석 여부, 올해 누적 출석률(80% 목표 대비), 최근 인증 내역을 확인합니다. |
| 출석률 관리 | 성공 인증 로그를 코드로 계산해 회원별 KST 주차의 0/100 출석과 연도별 누적 출석률을 `출석률` 시트에 기록합니다. |
| AI 이미지 코칭 | 인증 사진을 Ollama 멀티모달 분석에 보내 그룹 공유용 따뜻한 코칭 코멘트를 생성합니다. |
| 개인 정기 알림 | 메인 봇이 등록된 회원에게 아침 안내, 개인 대시보드, 저녁/출석 리마인더, 주간 TOP 3, AI 브리핑, 카드뉴스를 개인 DM으로 보냅니다. |

## 기술 스택

| 항목 | 기술 |
|------|------|
| 언어 | Python 3.10+ |
| 텔레그램 프레임워크 | `python-telegram-bot[job-queue]` |
| 저장소 | Google Sheets (`gspread`) |
| AI 엔진 | Ollama 로컬 API, 기본 모델 `gemma4:e2b` |
| 스케줄러 | Telegram `JobQueue` 기반 APScheduler |
| 이미지 생성 | Pillow 기반 카드뉴스 렌더러 |
| 환경설정 | `.env` + `python-dotenv` |

## 명령어 및 인증 방법

| 명령어 / 입력 | 사용 위치 | 설명 |
|--------|----------|------|
| `/start` | 어디서나 | 환영 메시지와 인증 방법 안내 |
| `/reg [인증 내용]` | **1:1 전용** | 텍스트로 즉시 루틴 인증 (`Routines` 조회 없음, 미등록 회원은 `Users`에 자동 추가 후 즉시 인증) |
| 📸 **사진 + 캡션** | **1:1 전용** | 사진과 캡션으로 즉시 루틴 인증 (`Routines` 조회 없음, 미등록 회원은 `Users`에 자동 추가 후 즉시 인증, AI 코칭 코멘트와 함께 그룹방 공유) |
| `/status` | 어디서나 | 나의 인증 횟수(오늘/이번 주/누적), 올해 출석률 현황 및 최근 인증 기록 확인 |
